Angular:
-------------------
A JS based single threaded front-end framework
It helps to create a SPA
declarative programming technique

features:
	components (template + code + metadata)
	MV-VM architecture
	services - data access/ business logic etc.
	dependency injection
	pipe - converters/transformers
	directives
	binding - data and event binding
	form data handling
	client-side routing
	angular modules
	etc.
