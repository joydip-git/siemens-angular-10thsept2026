@Component({}):
-----------------
Decorator that marks a class as an Angular component and provides configuration metadata that determines how the component should be processed, instantiated, and used at runtime.

bootstrapApplication():
---------------------------
Bootstraps an instance of an Angular application and renders a standalone component as the application's root component.

Binding:
------------------
1. passing data from code to the template of the component: data binding
	syntax:
	a. {{property-name}} => interpolation
	   or <element attr="{{property-name}}">

	b.[attr-name]="propty-name" => property binding
	 <element [attr]="property-name">

	note: interpolation strigifies the data before binding, which property binding syntax does not.

2. passing data from the template to the code of the component: event binding
	syntax:
	<element (event-name)="method(args)">

	code:
	method(data:any){....}

directives:
--------------
they are used like an attribute of an element which ONLY angular understands.
they
	- help you to manipulate DOM: structural directives
	  they are declared with * in template
	  example: *ngIf, *ngFor, *ngSwitch etc.
          nowadays are being replaced by @something...
	  example: @for, @if, @else, @elsif, @switch etc.

	- help you to extend the behavior of the element: attribute directives
	  they are NOT declared with * in template	
          example: ngClass, ngStyle, ngForm, ngModel, formElement etc.

	- help you render UI: component directives or components
	  they are declared with @Component() in code and will have template
	  note: no other directive has template
